## Cross-cutting notes

1. **One harmful route:** `lq_p1-02_average_velocity_02` m1. Its text is the correct method, so a
   student who reached 17 m would be marked as having made a mistake. This is the only item that
   would damage a correct solver.
2. **Route phrasing pattern (13 routes, all marked weak).** Two families recur:
   - "…instead of <the correct operation>" — `average_velocity_01` m2, `velocity_from_x_t_01` m2,
     `velocity_from_x_t_02` m1, `acceleration_from_v_02` m2, `acceleration_from_v_03` m1,
     `position_from_v_t_02` m1, `position_from_v_t_03` m1. Each names the right step inside the
     label a student is asked to pick, which no student holding that mistake would say.
   - "I used a different <value/factor> than the one given" — `average_velocity_03` m2,
     `velocity_from_x_t_02` m2, `position_from_v_t_01` m2, `position_from_v_t_03` m2. These assert
     the student deviated from data they believe they used, and none names a recognisable slip.
   The file already contains the correct pattern to copy: `velocity_from_x_t_01` m1 ("I treated the
   square term as if it becomes only t").
3. **Two distractors need an implausible unit conversion** (10 seconds per minute):
   `average_velocity_03` option 3 and `velocity_from_x_t_02` option 4. No common conversion slip
   reaches either value.
4. **Plain English (Rule 41):** two metaphor uses, both "drops out" (`velocity_from_x_t` check
   `why_wrong.3`, `acceleration_from_v` check `why_wrong.1`). No "simply", "obviously", "just", no
   personification, and no readiness claim anywhere in the file.
5. **Physics:** every marked answer in all 12 apply questions and all 4 checks is correct, and every
   concept card worked example follows step by step. No wrong answer key was found.
6. Structure checks that pass: 6 concept lines per card (5–8 allowed), one `r` route and exactly one
   `m` route per wrong option in every question, no route repeated within a question, no route over
   twelve words or containing a two-digit number, correct option number varied across questions,
   difficulty rising 1 → 2 → 3 in every subtopic.
