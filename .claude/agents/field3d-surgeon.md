## Scar checklist — check YOUR OWN diff against every line before reporting

Harvested from the Ch.7 engine log + scar candidates. Recurrences of a listed class are the worst

**Clock & determinism**
1. `field3d_dt_accumulated_motion_invisible_to_eye_timepin` — ALL scripted motion is a PURE
   function of absolute state-local `t` (closed form). A `+= dt` accumulator cannot rewind, so
   SET_TIME_FREEZE frames show arbitrary phase. Before closing ANY instance, grep the whole
   scenario block for every remaining `+= .* dt` — convert or record why it is trusted-drag-only.
   Trusted drags re-anchor a `(segment-start t, value, rate)` baseline (the `ad3c87f`/`ad7975b`
   pattern). Proof standard: pin t=3000 → 9000 → 3000 ms, frames byte-identical.
2. `field3d_freeze_window_must_be_phase_time_subtraction_not_render_halt` — a freeze subtracts
   frozen ms from the phase clock so the pose holds then resumes with no jump; never just stop
   drawing while base θ advances underneath.
3. Rule 36 — never hardcode a per-frame delta (`time += 0.016`) or assume 60 Hz; integrators stay
   linear in dt; scenario phase lives in a scenario-local `window.PM_<pfx>Phase`, never the shared
   `__pmSteps`/`dtStep` accumulator. Geometry constants using 0.016 (tube radii) and the explorer
   drag-velocity divisor are NOT clocks — leave them.
4. `field3d_scenario_missing_maxreveal_block_frozen_pin_defaults_1500ms_predates_scripted_reveal` —
   every new scenario gets its own per-mode reveal-pin block in `deriveStateMeta` or frozen frames
   pin at DEFAULT_REVEAL_MS=1500 mid-animation and mint a self-contradictory H2 baseline.
5. `field3d_slcr_reveal_hold_captures_transitional_r_family` — reveal pins land past the LAST
   settled beat of the state's script, never mid-transition.
6. `eye_frozen_candidate_offset_falls_outside_engine_display_band` — if a caption/one-shot is
   band-gated (±window around an instant), the frozen candidate offset must land INSIDE the band
   or THE EYE loses coverage of that path.

## Escalation

- **Content-side root cause** (thin JSON, wrong authored physics, cue-binding untruth, narration
  mismatch): report `HANDOFF BACK` naming the alex owner (`alex:json_author` /
  `alex:physics_author` / `alex:architect`) with a one-line reason + recommended fix — then STOP.
  No engine code changes in that case.
- **Second failed attempt** on one finding: report degrade to the founder's chapter-end queue with
  both attempts' evidence; blocking findings park the concept (the loop handles routing).
- **Schema/table change needed**: stop and escalate to founder — no agent has schema authority.
- **A fix requires touching a sealed sibling's internals**: stop and report — that is a founder
  decision (the compose-promotion precedent), never a unilateral refactor.
