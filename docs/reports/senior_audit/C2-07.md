## Teacher-gate questions

1. **Capital K vs small k.** `ts_ipe_c2_ck_rate_law` s1 `common_mistakes[1]` tells the student that
   "Writing capital K for the rate constant" is a mistake. NCERT uses small k, but the board's own
   source book ("FAST TRACK IPE for Sr. Students") prints capital K for the rate constant throughout
   this unit. If Telangana examiners accept K, this card is teaching a student to distrust the exact
   notation their textbook prints. Filed here, not as WRONG, because it is a live convention split —
   a teacher must rule on whether K is penalised.
2. **"Molecularity two" for the ester hydrolysis.** `ts_ipe_c2_ck_pseudo_first_order` prints
   "Molecularity is two, order is one" and `common_mistakes[1]` "Molecularity is fixed by the
   elementary step and stays two". Acid hydrolysis of ethyl acetate is a multi-step, H⁺-catalysed
   reaction, so strictly it has no molecularity at all — and the unit's own LAQ
   (`ts_ipe_c2_ck_molecularity_vs_order`, part 2/2) states that molecularity is defined only for an
   elementary step. The "bimolecular but first order" phrasing is nonetheless the standard Indian-text
   and source-book line for pseudo first order, so it is recorded here rather than as a finding.
   A teacher should confirm the board wants that sentence written.
3. **One mark for a definition the question does not ask for.** Four cards spend mark 1 on a
   definition the printed question does not request — "Give two examples for zero Order reactions"
   (1 mark for what zero order means), "Give two examples for gaseous first order reactions",
   "Give the units of rate constants…" (1 mark for how the unit is obtained), and
   `half_life_definition`'s example split. The `verification` note already flags the 1+1 split as the
   bank's CLAIM. A teacher should confirm the board awards half the marks to unrequested definition
   work, since the `margin_note`s tell the student the second half is not safe without it.
4. **2HI(g) → H₂(g) + I₂(g) appears twice in this unit with two different orders** — zero order here
   (`zero_order_examples`, on a gold surface) and elementary/bimolecular second order in the part-2/2
   LAQ. Both are chemically right and this card handles it correctly (the surface is named in the
   line, the `insider_note`, `common_mistakes[1]` and the `margin_note`). Raised only so the two
   halves of the unit are checked against each other before a teacher signs off.
