# C2-19 — Chemistry-II, Unit 11 d and f Block Elements (part 2/2)

Cards audited: 10 / 10   Findings: HARMFUL 0 · WRONG 3 · WEAK 5

Every card was solved from its `QUESTION:` line before its steps were read. A python script
(`chem.py`) parsed every printed formula (subscript/superscript normalisation, nested `[ ]`/`( )`,
`·nH₂O` hydrate notation) and machine-checked: the one printed reaction for atom AND charge balance;
the oxidation number → complex-ion charge → counter-ion count arithmetic for all 11 formulae of
`iupac_formulae_from_names`, all 4 of `iupac_names_of_complexes` and all 8 isomer formulae; and that
each isomer pair really is a pair (identical molecular formula on both sides — all four pairs pass).
A second script (`prose.py`) swept all 631 reader-facing strings for Rule-41 register and for prose
cloned between cards, and `struct.py` checked every `mark_split` sum, label pairing and step-mark
running total. Numbers were checked against NCERT Class 12: 3d first ionisation enthalpies
(V 650 < Ti 656; Co 758 and Ni 736 < Fe 762), Ln³⁺ radii (La³⁺ 106 pm → Lu³⁺ 85 pm, Δ = 21 pm),
atomic radii Zr 160 / Hf 159 pm, and μ = √(n(n+2)) = √35 = 5.92 BM for Mn²⁺. Figure stroke
coordinates were converted to angles and to energy-level displacements and checked geometrically.

## Teacher-gate questions

- **Ligand-name dialect.** The cards use the current IUPAC forms *chlorido*, *cyanido*, *aqua* while
  the source book prints *chloro*, *cyano*, *aquo*. Both are in wide Indian use and the cards say so
  on the step; a Telangana IPE examiner should confirm which form the board's key uses, because
  `iupac_names_of_complexes` is marked one mark per name.
- **`trioxalato` vs `tris(oxalato)`.** Item 6 of `iupac_formulae_from_names` is given as *potassium
  trioxalatochromate(III)*. NCERT itself writes "trioxalato…" for K₃[Al(C₂O₄)₃], but strict IUPAC
  wants `tris(oxalato)` for a ligand name that already contains a multiplying prefix. Board ruling
  needed on whether the strict form is also accepted.
- **Steel as an alloy example.** NCERT names steels under *Alloy formation* (via Cr, V, W, Mo, Mn)
  and also attributes the hardness of steel and cast iron to interstitial carbon. The WRONG row
  above flags the internal contradiction inside this one card, not the NCERT usage; a teacher should
  confirm which framing the board's key expects if both appear in one answer.
- **Mark splits.** Every `mark_split` on all ten cards is the bank's own claim (each card's
  `verification` field says so). They are internally consistent — see Notes — but unconfirmed.
