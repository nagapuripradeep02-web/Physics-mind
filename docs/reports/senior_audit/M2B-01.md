## Notes

- **Both book-correction claims in this group check out.** `ts_ipe_m2b_cir_direct_common_tangents_22x_minus4y`
  correctly identifies that the source book's printed pair-of-tangents line has a sign error
  (+1100x where it should be −1100x): multiplying the card's own two separately-derived tangent
  lines, (7x−24y−250)(3x+4y−50), gives exactly 21x²−44xy−96y²**−1100x**+200y+12500, confirming the
  card's correction and the book's misprint. `ts_ipe_m2b_cir_touch_externally_4x_6y_minus12`
  correctly identifies that the book's printed second-circle line (C₂=(−1,4), r₂=2) is a
  copy-paste of a DIFFERENT card's circle (verified: that is exactly `ts_ipe_m2b_cir_touch_externally_6x_2y_plus1`'s
  second circle, x²+y²+2x−8y+13=0) — the question's own circle x²+y²+6x+18y+26=0 gives C₂=(−3,−9),
  r₂=8, and the book's own next line (r₁+r₂=5+8=13) already uses the correct r₂=8, so the printed
  circle/radius line is simply the wrong paste, not a live disagreement.
