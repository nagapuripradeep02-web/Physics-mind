| ts_ipe_m1b_dif_ex_wrt_root_x | s2_divide | Two reader-facing prose fields state a false inequality. `margin_note`: "Dividing by 1/(2√x) multiplies by 2√x, so the answer is larger than eˣ, never smaller." `why`: "The fraction underneath is smaller than 1 near x = 0, so dividing by it must make the answer larger than eˣ." Both are false. 1/(2√x) → ∞ as x → 0⁺ (it exceeds 1 for every x < ¼, not falls below it), and 2√x·eˣ < eˣ for every 0 < x < ¼, with equality at x = ¼. The card's own `verification.note` records the counter-example without noticing it: at x = 0.25 the value is 1.284025417, which is exactly e^0.25 — not larger. This matters because `why` offers the claim as a self-check ("Checking that direction finds a fraction that has been turned the wrong way"), so a student who tests at x = 0.1 will reject the correct answer 2√x·eˣ and "fix" it to eˣ/(2√x). | Delete the size claim from both fields. Keep only the mechanics: dividing by 1/(2√x) is the same as multiplying by 2√x, which is where the factor 2√x on top comes from. If a check is wanted, it must be stated with its condition: the answer exceeds eˣ only for x > ¼. |
