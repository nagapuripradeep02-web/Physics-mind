## Notes

**Recomputations that came out right** (recorded so they are not re-done):

- `av_sqp_chain_od` — i: 1+3+1+2 = 7, j: 1−2+2+1 = 2, k: 1+1−2+3 = 3. OD = 7i + 2j + 3k, correct.
- All four coplanarity determinants expand to exactly 0, and the printed intermediate brackets are right: [2 + 30 − 32], [36 − 120 + 84], [48 − 24 − 24], [−60 + 126 − 66].
- `coplanar_find_lambda` — PS = i + 7j + (λ+1)k (the +1 comes from −(−k), as the card says); the expansion collects to 17λ + 146 = 0, λ = −146/17.
- `hexagon_sum` — with A at 0° … F at 300°, AB+AC+AD+AE+AF = (−6, 0) = 3AD = 6AO. ABDE and ACDF are genuinely rectangles, so AE = BD and AF = CD as claimed.
- `lines_intersect_a_plus_2b` — t = −1, s = −1; all three coefficient equations are consistent; point = a + 2b.
- `lines_intersect_minus_4c` — 6t − 2s = −1 and 8t + 2s = 1 add to 14t = 0; t = 0, s = 1/2, the b equation checks out, point = −4c.
- `rhombus_vertices` — all four sides 7; |AC| = √122, |BD| = √74. AB = DC, so the figure really is a parallelogram.
- `right_angled_triangle` — √41, √6, √35; 41 = 6 + 35; CB·CA = 2 + 3 − 5 = 0, confirming the right angle really is at C as the card claims.
- Every hyperbolic identity was checked against the eˣ definitions and every inverse-hyperbolic value against its log form; all correct, including the sign of the root in each.

**Two structural gaps, both standard IPE textbook practice — flagged for a teacher, not raised as findings:**

1. `ts_ipe_m1a_hf_cosh_five_halves` — from cosh x = 5/2 alone, sinh x = ±√21/2, so sinh 2x = ±5√21/2. The card takes the positive root silently and asserts "sinh x = √(cosh²x − 1)" as if it were the only value. Every IPE source does the same, so this is convention rather than an error.
2. `ts_ipe_m1a_vec_rhombus_vertices` — four equal side lengths in 3-space do not by themselves force a planar quadrilateral (a skew equilateral quadrilateral satisfies them). The proof as written never establishes planarity. It happens to hold here because AB = DC, but the card does not say so. Again the standard book proof.
