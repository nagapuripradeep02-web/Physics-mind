| ts_ipe_m1b_sl_vsaq_normal_form_3x_4y_12 | s2_divide_and_read_off | The card correctly gets cosα = −3/5, sinα = −4/5 (third quadrant), then prints **"Hence tanα = 4/3 ⇒ α = Tan⁻¹(4/3) ∈ Q₃"** and repeats it in the final line: "with α = Tan⁻¹(4/3) in the third quadrant". Tan⁻¹(4/3) is the principal value ≈ 53°8′, which lies in the FIRST quadrant — its cosine is +3/5, the opposite sign to the one the card just derived. A student copies an angle that contradicts the card's own cosα and sinα. Its own sibling card (`normal_form_x_y_1`) handles the identical situation correctly by writing 225°. | `tanα = 4/3, and since cosα and sinα are both negative, α = 180° + Tan⁻¹(4/3) ≈ 233°8′ (third quadrant)`. The final line should read `x cos α + y sin α = 12/5 with α = 180° + Tan⁻¹(4/3)`. |
| ts_ipe_m1b_sl_vsaq_area_find_a | s1_read_off_the_coefficients | The card compares 3x + 4y − a = 0 with **ax + by + c = 0** and prints **"a = 3, b = 4, c = −a"** — the letter `a` is the question's unknown AND the general x-coefficient at the same time. Read literally the line asserts a = 3 and c = −3 together, which gives area 9/24, not 6. Step 2 then silently uses the other reading, (−a)² = a² with a the unknown, to reach a² /24 = 6. This is exactly the "printed line is wrong, next line is computed from the correct version" shape: the boxed answer a = ±12 is right and hides it completely. | Use different letters for the general form, e.g. "comparing with lx + my + n = 0 we get l = 3, m = 4, n = −a", then Δ = n²/(2\|lm\|) = a²/24. (Or keep ax+by+c=0 and rename the unknown, e.g. 3x + 4y = k.) The unknown must never share a letter with a coefficient it is compared against. |
