## Teacher-gate questions
- **Ethidium bromide staining order.** NCERT prints the sequence as separate → stain → UV; in every working laboratory the dye is cast into the gel or the buffer before the run. `visualise_dna_on_gel` s1 turns the NCERT order into a rule and calls the other order a mistake. Does the board mark the order at all, and if so which one? This decides the WRONG row above.
- **"The SAME restriction enzyme" as an absolute.** `recombinant_dna` s2 `common_mistakes[1]` says "Saying different enzymes are used on the two DNAs. The SAME one must be used." NCERT does teach the same-enzyme rule ("if the source DNA and the vector DNA are cut by the same restriction enzyme, the resultant fragments will have the same kind of sticky-ends"), but two *different* enzymes that leave compatible sticky ends also work. Left as printed, since it is NCERT's own teaching — confirm the board expects the absolute.
- **Palindrome wording.** NCERT: "reads same on the two strands when orientation of reading is kept the same", plus "this is also true if read in the 3'→5' direction". The card mandates the literal phrase "in the same 5' to 3' direction". Does the board require that exact phrase, or accept "read in the same direction"?
- **How many PCR uses.** The guide-book prints three (cloning, gene amplification, DNA fingerprinting); NCERT's emphasis is amplification of a gene of interest plus molecular diagnostics (HIV detection, suspected cancer mutations). Is the three-item list what the board expects for the second mark, and is early disease detection accepted as a fourth?
- **"Regenerating a circular molecule."** `recombinant_dna` s2 uses NCERT's own phrase, which is true when the vector is a plasmid but not of every vector or of a linear construct — while s1 defines the vector generally. Should the line stay as it is, or say "when the vector is a plasmid"?
- **Named source enzyme.** `molecular_scissors` s2 answers "usually obtained from BACTERIA". NCERT carries the naming convention (EcoRI from *Escherichia coli* RY 13). Does this 1-mark half want a named example enzyme with its source organism, or is "bacteria" the full answer?
